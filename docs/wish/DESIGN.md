# Wish design — GDKVM public re-release

The public repository is a release surface, not the private remediation workspace.

- public code, reproducibility assets and release-facing evidence may live here;
- private audits, intermediate experiments and release preparation stay in `mykcs/gdkvm-rerelease`;
- large research artifacts should use the governed artifact store when appropriate rather than bloating Git history;
- public claims should trace to reproducible evidence.

When public clarity and private completeness conflict, publish the smallest sufficient reproducible surface and keep sensitive/internal material private.
