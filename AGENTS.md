# Repository Agent router

Shared operating policy: follow [the central AGENTS.md](https://github.com/mykcs/.agents/blob/main/AGENTS.md) and [Capability Routing](https://github.com/mykcs/.agents/blob/main/docs/dev/CAPABILITY_ROUTING.md) for authorization reuse, tool fallbacks and engineering completion. This repository retains its scoped scientific, resource, privacy and release requirements.

This is the **public GDKVM re-release surface**. Keep it clean, reproducible, and suitable for external readers.

Before changing content or code:
1. read `README.md`;
2. read `docs/wish/README.md`;
3. read `docs/dev/README.md`;
4. inspect the exact source/test/repro path affected.

Private remediation, unpublished evidence, credentials, internal infrastructure details, and sensitive artifacts belong in their private owners, especially `mykcs/gdkvm-rerelease`. Do not copy them here merely to make the public repository self-contained.

Never fabricate benchmark results or loosen reproducibility claims to simplify release.
